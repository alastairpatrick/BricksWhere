# Installing BricksWhere

If you have not already, first install [python](https://www.python.org/) and [pip](https://pip.pypa.io/en/stable/installation/), according to their documentation.

Clone the github repository:
```> TODO```

Create and activate a virtual environment:
```
> cd BricksWhere
> python -m venv env
> env/Scripts/activate
```

Install dependencies:
```
> pip install -r requirements.txt
```

Running tests
```
> pip install -r requirements.txt
> python -m pytest
```

# Launching BricksWhere

Once installed, activate the environment and run BricksWhere:
```
> cd BricksWhere
> env/Scripts/activate
> python app.py

GUI
```
